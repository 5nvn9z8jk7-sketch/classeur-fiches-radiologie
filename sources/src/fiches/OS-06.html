Dysplasie de la trochlée · classification de Dejour

Type ASigne du croisement ; trochlée peu profonde, facettes de forme normale
Type BCroisement + éperon sus-trochléen ; trochlée plate en coupe
Type CCroisement + double contour ; facette médiale hypoplasique, latérale convexe
Type DCroisement + éperon + double contour ; falaise entre les facettes
Signes sur le profil strict du genou : croisement (le fond de la trochlée rejoint le bord antérieur du condyle latéral), éperon sus-trochléen, double contour (condyle médial hypoplasique), bosse sus-trochléenne. Corréler au scanner ou à l'IRM.
